This project simulates a small business connected through an ISP environment. It demonstrates VLAN segmentation, inter-VLAN routing, DHCP deployment, OSPF dynamic routing, NAT/PAT, ACL troubleshooting, connectivity testing, and structured network diagnostics.

The project goes beyond configuration by demonstrating how network failures can be identified, isolated, corrected, and verified using a systematic troubleshooting methodology.
