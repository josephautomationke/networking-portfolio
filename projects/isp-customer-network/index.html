📌 Project Overview

This project simulates a business connected to an ISP environment using Cisco Packet Tracer. The network was designed to support multiple departments while ensuring proper routing, segmentation, and internet connectivity.

The focus of this project was not only configuration, but also troubleshooting and operational diagnostics.

⚡ Technologies & Concepts

🌐 OSPF Routing

Configured dynamic routing between routers and verified adjacency relationships.

🔀 VLAN Segmentation

Separated departments using VLANs and enabled Inter-VLAN communication.

📡 DHCP Deployment

Implemented automatic IP assignment and resolved DHCP-related failures.

🌍 NAT/PAT

Configured internet simulation and verified translation behavior.
