# 🌐 ISP Customer Network Deployment & Troubleshooting

> A practical Cisco Packet Tracer project demonstrating network deployment, VLAN segmentation, inter-VLAN routing, DHCP, OSPF, NAT/PAT, ACL troubleshooting, connectivity testing, and structured fault diagnosis.

---

## 🚀 Project Overview

This project simulates a small business network connected through an ISP environment using Cisco Packet Tracer.

The goal was to demonstrate more than basic device configuration.

The project follows a complete operational workflow:

```text
Design
   ↓
Configure
   ↓
Test
   ↓
Introduce Failure
   ↓
Diagnose
   ↓
Fix
   ↓
Verify
   ↓
Document
